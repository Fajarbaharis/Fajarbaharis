### Featured Engineering Projects

* **[fajar-mint-setup](https://github.com/Fajarbaharis/fajar-mint-setup)**  
  *Automated Linux Mint Provisioning & Performance Optimization Toolkit*  
  An idempotent post-install automation suite engineered to transform vanilla Linux Mint systems into high-performance environments. Integrates transparent memory compression (ZRAM zstd 50%), kernel sysctl memory management, automated Intel power cap (RAPL/MSR) throttling recovery, and real-time terminal system diagnostics.

* **[Pilah-Sampah-Cerdas (Berseka Ecosystem)](https://github.com/JexyDev/Pilah-Sampah-Cerdas)**  
  *Intelligent Waste Segregation & IoT Ecosystem*  
  A full-stack, computer vision-assisted smart waste classification system. Incorporates containerized database services (PostgreSQL, Redis), model inference pipelines, and edge-device hardware telemetry for automated environmental sustainability tracking.
